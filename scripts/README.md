# scripts/

Каталог для **хост-скриптов** (не входят в прошивку).

Здесь размещаются вспомогательные shell-скрипты для разработки:
сборка, прошивка платы, запуск эмулятора, деплой утилит, генерация
ресурсов и т.п.

Пример:

```
scripts/
├── .gitkeep
├── build_firmware.sh   # сборка прошивки (CI / локально)
├── flash_board.sh      # прошивка платы через J-Link
└── README.md
```
