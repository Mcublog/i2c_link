# docs/

Каталог для **документации проекта**.

Здесь размещается документация, не входящая в исходный код:
- описание бинарных форматов (`data/`);
- внешняя документация, PDF, даташиты (`extdocs/`, `datasheets/`);
- схемы и документация плат (`board/`);
- прочие проектные документы.

Пример:

```
docs/
├── .gitkeep
├── datasheets/   # даташиты
├── data/         # описания форматов
├── extdocs/      # внешняя документация (PDF и т.п.)
└── README.md
```
