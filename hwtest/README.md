# hwtest/

Каталог для **тестов на железе** (не входят в обычную сборку).

Здесь размещаются тесты, которые запускаются на реальной плате (например,
проверка GPIO, периферии, таймеров) и требуют подключённого Железа.

- В сборку `hwtest/` **не включается** — `add_subdirectory(hwtest)` в
  корневом `CMakeLists.txt` закомментирован.
- Для включения тестов на железе в сборку раскомментируйте соответствующую
  строку в корневом `CMakeLists.txt`.
- Для запуска через Makefile используйте цель `make hwtests`.

Пример структуры:

```
hwtest/
├── .gitkeep
└── README.md
```
